RAVENNA CAFE — HTML / CSS / JavaScript
======================================

File structure:
  index.html       Main page structure
  style.css        Layout, colors, typography, responsive design and animation
  script.js        Scroll reveal, hero pointer interaction, menu filter, toast and demo newsletter
  assets/          Local image assets cropped from the reference screen recording you provided

How to run:
1. Extract the ZIP file.
2. Open the ravenna-cafe-html folder in Visual Studio Code.
3. Open index.html with Live Server (recommended), or open index.html directly in a browser.

Notes:
- Google Fonts are loaded from fonts.googleapis.com, so internet is needed for the custom typefaces.
- All images in assets/ are local and work offline.
- The newsletter is a front-end demo only. It does not send or save email addresses.
- The product buttons show a demo toast. Connect them to WhatsApp, a cart, or a checkout service for real orders.
- Update address, opening hours, Instagram and contact links before publishing.
